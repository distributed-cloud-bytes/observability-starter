# Kikplate badges

This starter is published on [Kikplate](https://kikplate.dev/plates/observability-starter). Badge shields in the root [README](../README.md) reflect the qualities the template is designed for.

## Target badges

| Badge | Slug | Why it applies |
|-------|------|----------------|
| Documented | `documented` | `docs/README.md` hub, architecture, configuration, operations, development |
| Docker Ready | `docker-ready` | `docker compose up`, Makefile targets, validated Compose CI |
| Well Tested | `well-tested` | Compose validation workflow in CI |
| Cloud Native | `cloud-native` | Containerized Prometheus/Grafana, metrics for services |
| Beginner Friendly | `beginner-friendly` | Standalone quick start, clear defaults |
| Security Friendly | `security-friendly` | [SECURITY.md](../SECURITY.md), local-dev credential guidance |

## Official badge

The **Official** (`official`) badge is granted only by [Kikplate administrators](https://github.com/kikplate/kikplate). Plate owners can request it after the template is verified and documentation is complete.

To show badges on the Kikplate plate page (not only in this README), ask Kikplate maintainers to grant: `documented`, `docker-ready`, and related community badges for plate ID `observability-starter` under org `distributed-cloud-bytes`.
