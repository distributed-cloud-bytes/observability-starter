# Contributing

Thank you for improving **observability-starter**.

1. Fork `distributed-cloud-bytes/observability-starter`
2. Branch from `main`
3. Keep dashboards and rules generic (use variables, avoid product-specific names)
4. Run `docker compose config` before opening a PR
5. Open a pull request with screenshots or test notes when changing dashboards
6. When you change ports, networks, Make targets, or user-facing behavior, update the root [README](README.md) and the relevant guide under [docs/README.md](docs/README.md)
