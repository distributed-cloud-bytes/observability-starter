# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| `main` | Yes |

## Reporting a vulnerability

Do not open public issues for security vulnerabilities.

Use [GitHub security advisories](https://github.com/distributed-cloud-bytes/observability-starter/security/advisories/new) for this repository.

## Scope

Local development observability stack only. Change default Grafana credentials before any shared environment.
